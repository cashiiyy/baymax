# B.A.Y.M.A.X. v1 – Intelligence First

Local, multimodal AI health assistant architecture built with FastAPI, FAISS, SQLite, Qwen, Faster-Whisper, and Coqui XTTS.

## Repository Layout
```
baymax/
├── backend/
│   ├── api/          # FastAPI REST endpoints
│   ├── database/     # SQLite database models & session
│   ├── memory/       # Conversation context & saved facts
│   ├── rag/          # Medical RAG search engine & FAISS retriever
│   └── logging/      # Structured JSON logging
├── ai_engine_1/      # Medical Reasoning Brain (LLM, Embeddings, Tools)
├── ai_engine_2/      # Multimodal Engine (Faster-Whisper, Coqui XTTS, OCR, Vision)
├── nginx/            # Nginx config for Tailscale IP 100.89.251.123
├── datasets/         # Knowledge base datasets
├── scripts/          # Tailscale setup scripts
├── tests/            # Automated test suite
├── Dockerfile        # Container build specification
└── docker-compose.yml# Multi-container service definition
```

## Setup & Running

### 1. Virtual Environment
Activated in `venv/`:
```powershell
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Run Local Development Server
```powershell
uvicorn backend.api.main:app --host 0.0.0.0 --port 8000 --reload
```

### 3. Tailscale Access
Connect to the server from any local machine on your Tailscale network:
```
http://100.89.251.123:8000
```

### 4. Running with Docker & Nginx
```bash
docker-compose up --build
```
Nginx listens on port `80` forwarding to `100.89.251.123`.

## Medical Educational Safety
All responses generated by B.A.Y.M.A.X. automatically include a safety review header/footer reminding users that guidance is strictly educational and not a substitute for professional medical care.
